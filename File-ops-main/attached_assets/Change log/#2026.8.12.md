## Tailscale Funnel

#2026.8.12

Purpose
  > Tailscale ネットワーク (tailnet) 上のデバイスで動いているローカルサービスに、インターネット全体からのトラフィックをルーティングする

Prerequisites・Limitations
  > Tailscale v1.38.3以降
  > MagicDNS
  > HTTPS certificate
  > Funnel node attributes
  > Tailnet domain
  > Port: 443・8443・10000
  > TLS encrypted connection

Setup procedure for Windows11

```powershell
cd C:\WorkHub\repos\Spec\File-ops-main\file-browser

# 仮想環境の作成
python -m venv .venv
.venv\Scripts\activate

# 依存関係のインストール
pip install -r requirements.txt

# 環境変数の設定(このPowerShellセッション内のみ有効)
$env:FILE_BROWSER_BASE_DIR = "C:\WorkHub\projects"
$env:FILE_BROWSER_PORT = "8000"

# 起動
python app.py
```

Map port 8000 to public port 10000 using Tailscale Funnel
```powershell
tailscale funnel --bg --https=10000 8000
```

Node-specific authorization link
```URL
https://login.tailscale.com/f/funnel?node=nLP5k1H8i321CNTRL
```

Access link
```URL
https://win.tailb112a4.ts.net:10000
```

Tailscale Management Console

Allowing Funnel in the Tailscale policy file
```json
"nodeAttrs": [
  {
    "target": ["autogroup:member", "tag:devices"]
    "attr": ["funnel"],
  },
],
```

Troubleshooting

Reset funnel
```powershell
tailscale funnel --https=10000 off
tailscale funnel --bg --https=10000 8000
```

Additionally enabled HTTPS for local/tailnet access (port 8000)
```powershell
tailscale serve --bg --https=443 8000
```
  > URLs with Tailscale-issued certificates can be used exclusively by members within the tailnet


## Automatic startup settings

#2026.8.12

Step 1: Change the environment variable setting from "set each time" to "permanent setting."
```powershell
[Environment]::SetEnvironmentVariable("FILE_BROWSER_BASE_DIR", "C:\WorkHub\projects", "User")
[Environment]::SetEnvironmentVariable("FILE_BROWSER_PORT", "8000", "User")
```


Step 2: Register a task to launch automatically in the background upon login.
```powershell
$action = New-ScheduledTaskAction -Execute "C:\WorkHub\repos\Spec\File-ops-main\file-browser\.venv\Scripts\pythonw.exe" -Argument "app.py" -WorkingDirectory "C:\WorkHub\repos\Spec\File-ops-main\file-browser"

$trigger = New-ScheduledTaskTrigger -AtLogOn

Register-ScheduledTask -TaskName "FileBrowser" -Action $action -Trigger $trigger
```

Operational check
```powershell
Start-ScheduledTask -TaskName "FileBrowser"
```
